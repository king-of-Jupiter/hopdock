# Hopdock

Desktop SSH client, Termius-like MVP. Solo hobby project, Electron + React + TS.
Working title, verified clean in search. See `PLAN.md` for the full plan.

## Install

Download the latest release for your OS from
[GitHub Releases](https://github.com/king-of-Jupiter/hopdock/releases).

### macOS (unsigned build)

There is no paid Apple Developer signature yet, so Gatekeeper blocks the
first launch with "Hopdock.app is damaged". Workaround after copying the
app to Applications:

```bash
xattr -cr /Applications/Hopdock.app
```

then open it via right-click → Open. A proper Developer ID signature +
notarization will come with funding; the DMG background and icon are
already wired (`apps/desktop/build/`, generated by `tools/make-artwork.py`).

## Quickstart

```bash
npm ci
npm run dev        # Electron with hot reload
```

Supabase URL and public key are embedded at build time. Copy `.env.example` to
`.env.local` and set `SUPABASE_URL` and `SUPABASE_PUBLISHABLE_KEY`. CI uses GitHub
repository variables with the same names. See [vault sync setup](docs/password-sync.md)
for GitHub integration, migrations and encryption settings.

### Continue development on macOS

Install Node.js 22, Python 3.11 (for the bundled Termius importer), and Xcode
Command Line Tools. Then:

```bash
git clone https://github.com/king-of-Jupiter/hopdock.git
cd hopdock
npm ci
cp .env.example .env.local
# Set the public Supabase project URL/key in .env.local if sync is needed.
python3 tools/build-termius-reader.py
npm run dev
```

For an existing checkout, use `git pull --ff-only` instead of cloning. Read
`AGENTS.md` before continuing: it records the agreed design and behavior.
Build the Termius reader on the Mac itself; the Windows executable is not portable.
The application starts with an empty local library. Host credentials are not in
Git; restore them through vault sync or import the local Termius profile.

## Layout

```
apps/desktop       Electron shell (main/preload) + React renderer
packages/core      vault/host/key/snippet models + mock data (shared with future mobile)
packages/ui        design tokens (CSS vars) + AppShell/Sidebar/HostList/HostForm
supabase/          (M3+) schema + RLS for personal/shared vault sync
```
